# Monster Land

A learning-through-play game for young children (about 4 years old). The child plays with three friendly monsters, Moko, Gumi and Tobi.

**Play:** open the GitHub Pages address of this repository on a tablet held sideways. It can be added to the home screen and keeps working offline after the first visit.

## Games

- **Find it:** English words, categories and first letters
- **Count it:** counting, adding, taking away and story problems
- **Shape it:** shape puzzles and building pictures
- **Sort it:** colours, shapes, sizes and groups
- **Train time:** fix the railway, use junctions and deliver the animals
- **Treasure:** plan the path with bridges, springs, balloons and ramps, then press Go
- **Race:** answer while running against the other two monsters

Each round has 5 questions, and the level adjusts to the child. A parent corner sits behind the lock button (protected by a grown-up maths question) for the child's name, a daily time limit and music.

## Technical notes

Plain HTML, CSS and JavaScript modules, with no build step. All pictures are drawn in code as SVG. Voices use the device's built-in English speech. Progress is stored only on the device.
